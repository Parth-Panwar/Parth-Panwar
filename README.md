# 🧠 Featured Projects

## 🕵️ Beyond The Pixel — Deepfake Detection System

A full-stack deepfake detection system trained on DFDC datasets using EfficientNet + face cropping pipelines.

### Features

* 🎭 Deepfake image & video detection
* 🧠 CNN/EfficientNet based classification
* 🎥 Frame extraction & analysis
* 🖥️ Full-stack integration
* 📊 Confidence scoring system

**Tech Stack:** Python, TensorFlow, OpenCV, Flask

---

## 👁️ Vision Assistant For Visually Impaired

Real-time object detection system capable of detecting objects and speaking them aloud using text-to-speech.

### Features

* 📷 Real-time webcam detection
* 🔊 Voice output
* 🎯 Bounding box tracking
* 🧠 CNN + ResNet experimentation

**Tech Stack:** Python, OpenCV, TensorFlow, pyttsx3
